# 喵喵成行 🐾

一款给两个人一起玩的像素风小猫网页游戏：黑猫和白猫，一起闯关回家，也可以来一场对战小游戏。

**在线玩：** https://ruinncode.github.io/miaomiao-chengxing/

## 怎么玩
- **在线双人：** 一个人点「创建房间」，把链接（`…/?room=房间码`）发给对方；对方打开链接或输入4个字母的房间码点「加入」。房主是黑猫，负责选择玩法。
- **同一台设备：** 点「同一台设备 · 双人」。黑猫 WASD + F，白猫 方向键 + 回车。
- **按键：** 移动 WASD/方向键 · 跳 W/↑/空格 · 动作 F/J/回车 · 喵 E/M · 重来 R。手机上有触屏按钮。

## 玩法
- **合作闯关（5关）：** 一起回家 · 按住机关开门 · 推纸箱当台阶 · 叠猫猫 · 全部用上！
- **对战小游戏（五局三胜）：** 抢小鱼 · 猫拳擂台 · 躲避扫地机

纯静态网页（Phaser 3 + PeerJS），无需安装。像素字体：Zpix（个人免费使用）。
