# 喵喵成行 🐾

一款给两个人一起玩的像素风小猫网页游戏：**jsq**（系蓝绿色围巾、挂圆形名牌的黑猫）和 **yyf**（戴黄色铃铛项圈的棕色虎斑猫），一起闯关回家、去旅行，也可以来一场对战小游戏。

**在线玩：** https://ruinncode.github.io/miaomiao-chengxing/

## 怎么玩
- **在线双人：** 一个人点「创建房间」，把链接（`…/?room=房间码`）发给对方；对方打开链接或输入房间码点「加入」。房主是 jsq，负责选择玩法。
- **同一台设备：** 点「同一台设备 · 双人」。jsq：WASD + F；yyf：方向键 + 回车。手机上有触屏按钮。

## 玩法
- **合作闯关（10 关）** 和 **对战小游戏**（抢小鱼 · 猫拳擂台 · 躲避扫地机，五局三胜）。
- **大厅：** 一起旅行（出发大厅 → 收拾行李 → 飞机/火车 → 酒店 → 逛街、坐地铁、打卡活动 → 晚安）、小游戏厅、MIAO·BOY 掌机、一起自习、旅行日记。
- **11 座城市：** 多伦多、滑铁卢、东京、京都、巴黎、纽约、波士顿、温哥华、伦敦、首尔、香港。线路和站名参考真实资料（见 docs/TRAVEL_NOTES.md，仓库内）；店铺和酒店是虚构的。
- **多伦多实景模式：** 街上或酒店「窗外风景设置」里可切换像素画 / 实景照片（Wikimedia Commons 开放授权照片，见 CREDITS.md）。
- **音乐：** 代码生成的原创 lo-fi；也可以选「自己的音乐」只在本机播放（不支持 MIDI 导入）。

纯静态网页（Phaser 3 + PeerJS），无需安装。像素字体：Zpix。署名与授权见 CREDITS.md。
